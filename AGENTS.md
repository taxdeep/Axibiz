# UI preferences

- Prefer English for new and modified interface text.
- Keep desktop forms compact. Reserve space for primary actions so they remain visible at smaller window sizes.
- Use applicable saved local exchange rates first and fetch missing data automatically in the background. Do not add a manual refresh button to invoice forms.
- Preserve date-aware exchange-rate validation, business window singleton rules, and unsaved-input protection.
- Avoid duplicate plain Close buttons in native business windows; use the system title-bar X with the existing unsaved-input checks. Keep Save & Close actions and embedded-dialog close controls where needed.
