# Sales Tax 使用说明（0.6.0）

## 设置与录入

1. 打开 **Setup → Sales Tax**，选择 CRA / BC PST 机构，填写实际注册税号、确认已注册，并检查应缴税及进项抵扣科目。默认未注册，现有业务税码仍为 NONE，不会自动加税。
2. 在“税目与生效税率”维护税目与历史税率，在“税码组合”维护供未来单据使用的税码。税率变更须追加生效日，不覆盖同日历史；支持四位小数百分比，不支持税上加税的复合计税。
3. 在“分配默认税码”设置 Price List、Customer、Vendor。新 Task 行优先采用显式行税码，其次非 NONE 的价格单税码，再其次客户默认税码。已有行不自动改变，可在 Task Edit 逐行选择税码并 Save。切换业务后恢复新业务的默认税码。
4. Task 售价和合计为未税金额。Invoice 按开票当天的温哥华日期选取税率，逐行逐税目以整数分计算、四舍五入；保存税码、税率、生效日、机构、税号、科目、税额快照。Invoice 付款余额按含税总额计算，同一张合并发票可包含不同税码。
5. Expense 每行可选择税码、“含税录入”及实际合资格可抵扣百分比。含税拆分采用同一未税基数，分值尾差分配到末尾税目。机构已注册并填写税号、配置抵扣科目，且税目允许抵扣时，才计算进项抵扣；PST 默认不抵扣。费用单合计为含税应付金额，成本为含税金额减可抵扣税额。Task 编辑页额外费用也可选择税码与含税方式。

默认税码如下。预设不自动判断具体业务的供应地、免税或 PST 适用条件。

| 税码 | 用途 |
|---|---|
| NONE | 未指定 / 不计税，兼容旧数据 |
| G | GST 5% |
| P | BC PST 7% |
| S | GST + BC PST |
| H-ON | Ontario HST 13% |
| H-NS | Nova Scotia HST，2025-04-01 起 14%，此前支持 15% |
| H-15 | NB/NL/PE HST 15%，支持 2016-10-01 及以后 |
| Z | 全部零税率，单独保存 zero 分类 |
| E | 全部免税，单独保存 exempt 分类 |

不同税种需不同处理时，可建立自定义组合；同一组合不允许同时使用 GST 和 HST。第一版不预设 QST。税率不会随联网同步自动覆盖。

## 税款与报表

通过左侧 **Sales Tax** 或 **Report → Sales Tax** 查看期间销项、可抵扣进项、期间净额和截止日累计余额，均以 CAD 对账。

余额 = 累计销项 − 累计可抵扣进项 + 调增/退款 − 调减/缴款。负数表示净抵扣或预缴余额；客户收款时间不改变已开票销项税。

可登记 CAD 缴款、退款、调增、调减，须填写原因或凭证；错误记录可撤销并保留原记录及审计日志。这是登记已发生的税款，不会向银行或税局发起付款。税款原交易保留在原日期，撤销按撤销日期计反向变动；截至日余额不会因之后撤销而抹去原交易。旧撤销日期只有存在原 GL 冲销凭据时才恢复，无法核实的记录由 Accounting Checks 提醒人工核对。

汇总、明细、待核对报表均可导出 CSV。明细包括有效缴款/调整及明确的 Z/E 单据；待核对列出 NONE 或升级前缺少税额快照的单据，不代表这些单据一定需要补税。

## 外币与历史数据

外币税额保存 CAD 折算快照：手工 CAD 汇率优先，否则取单据日及之前七天内最近本地日汇率。缺少适用报价时停止保存；可以同步汇率或在汇率页手工填写适用于该单据的报价。手工汇率没有历史日期，录入者须确认其适用性。不会使用单据日之后的自动日汇率。

保存原币种、原税额、CAD 税额及抵扣额、汇率及参考日期。只改费用说明保留原税额和汇率；更新配置不改历史发票快照。已有费用保留原金额，不自动追溯计算税额，编辑时应根据实际凭证确认税码和金额口径。

业务数据与税务流水在同一事务提交，失败一起回滚。备份恢复会核对税额快照、来源单据及 CAD 换算。应缴税、进项抵扣科目默认创建为负债、资产类型；若预期编号已有其他用途，会另建税务科目，不覆盖原科目。

当前实现税务子账和对账导出；0.10.0 起新业务同步生成 [GL 分录](GENERAL_LEDGER.md)，历史记录不追溯。手工 GL 的 Tax reference 不改变税务子账，税款调整请通过 Sales Tax 登记。尚无网上申报、申报期封账、Quick Method、自动 PST 佣金或销售退款/贷项通知单。

## 业务适用性

税码需要按实际供应地点、服务性质、登记状态和证据选择，NONE 不代表已经确认免税。2026-09-18 BC 政府宣布暂停原计划 2026-10-01 实施的部分专业服务 PST 扩围，不能依旧预算公告对全部专业服务自动收 PST；见 [官方公告](https://archive.news.gov.bc.ca/releases/news_releases_2024-2028/2026PREM0034-001089.htm)。代理垫付、费用转收、混合用途和 ITC 资格必须另行判断，本工具不提供自动税务意见。
